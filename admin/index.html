🛡️ Minh Bạch Kỹ Thuật Về Cơ Chế Quản Trị Website Tĩnh (Static Site):

Website LIDO vận hành theo kiến trúc Jamstack / GitOps Tĩnh (0 VND), không có máy chủ backend chạy ngầm. Để đảm bảo an toàn tuyệt đối:

  1. Trang này đóng vai trò là Trình tạo file cấu hình (Offline Config Generator). Mọi thông tin mật khẩu được loại bỏ hoàn toàn khỏi mã nguồn để tránh lỗ hổng bảo mật.
  2. Sau khi bạn chỉnh sửa xong các mục bên dưới, nhấn nút "💾 Tải File site_data.json Mới".
  3. Ghi đè file vừa tải vào thư mục data/site_data.json và đẩy lên GitHub (hoặc kéo thả lên giao diện web của GitHub). Website toàn cầu sẽ tự động cập nhật ngay lập tức.
